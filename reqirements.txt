    -- SCSS
    -- Eslint (чистота кода)
    -- 2 modes
        --- Dev
        ---- Dev Server (перезагружать сервак при сохранении),
        ----SourceMaps (исходные карты, добавляется для scss файлы - показывать модули где велась разработка),
        ----Eslint (Поддержка чистоты кода и для содержания кода в едином стиле),
        ----Not Minified JS & CSS (Как выглядит код при разработке)
    --- Prod
        ---- Minified Code (Сжатие кода для уменьшения размера и увелечения оптимизации)
-Git (следит за версионностью проекта)
    --GitFlow (способ взаимодействия с Git)
    Существует две версии приложения
        PROD
        Development
        Обозначение версий
        1.0.0 - гдe:
            - 1.0.1 - последняя цифра отвечает за небольшие изменения, т.е смена цвета и т.д.
            - 1.1.0 - вторая цифра отвечает за серьезные изменения, добавление toolbar и т.д.
            - 2.0.0 - первая цифра отвечает за кардинальные изменения

    Схема взаимодействия (пример):
    Production
    1.0.0
    0 (master) --------
    Development
    1.0.2

    1 (develop)---------- + ---PR (запрос на совмещение ветки после удачного идет совмещение веток и добавляется изменения который делал разработчик в рамках новой фичи после завершения ветка 2 удаляется )
    2 (feature/name-feature)---| (копирование ветки для разработки новой фиче в гите это создание новой ветки (branch))
